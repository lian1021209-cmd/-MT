# 地鐵路網繪製器 (Metro Network Drawer)

專業地鐵與捷運路網繪製工具，支援自由節點、虛擬節點、8 方位站名與可任意拖動自由站名、八方軸向與紅色虛線等距吸附、多種路線轉折與任意角度旋轉等功能。

---

## ❓ 為什麼下載解壓後的檔案無法直接點開？

如果您解壓縮後**直接用瀏覽器雙擊開啟 `index.html`**，會發現畫面是**一片空白（白屏）**，這是正常的！

### 原因說明：
1. **現代化工程架構**：本專案是以 **React 19 + TypeScript + Vite + Tailwind CSS** 建構的現代前端專案。
2. **瀏覽器安全限制 (CORS)**：`index.html` 中引入的是原始碼 `src/main.tsx`，標準瀏覽器**無法直接在本地檔案協定 (`file:///`) 下執行 TypeScript 模組**，會被瀏覽器的安全機制阻擋。
3. **依賴套件未包含**：為了讓 ZIP 下載檔案保持輕巧，下載的原始碼包**不包含數百 MB 的 `node_modules` 套件庫**，需要在您的電腦上透過 `npm install` 載入依賴才能運行。

## 🚀 如何在本地電腦運行（簡易教學）

### ⚡ 方式一：一鍵自動啟動（最簡單）

#### 🔹 Windows 使用者：
1. 確保電腦已安裝 [Node.js](https://nodejs.org/)（推薦安裝 LTS 版本）。
2. 在解壓後的資料夾中，**直接滑鼠雙擊執行 `start.bat`**。
3. 程式會自動安裝依賴套件並啟動伺服器，自動開啟瀏覽器進入 `http://localhost:3000`！

#### 🔹 macOS / Linux 使用者：
1. 確保電腦已安裝 [Node.js](https://nodejs.org/)。
2. 在資料夾中打開終端機（Terminal），執行：
   ```bash
   bash start.sh
   ```

---

### 💻 方式二：手動終端機指令啟動（推薦開發者）

1. **安裝 Node.js**：
   前往官網 [https://nodejs.org/](https://nodejs.org/) 下載並安裝 Node.js（LTS 版本）。

2. **開啟終端機 (Terminal / 命令提示字元)**：
   在解壓縮的資料夾中按右鍵開啟終端機（或在終端機中 `cd` 進入該目錄）。

3. **安裝依賴套件**：
   ```bash
   npm install
   ```

4. **啟動本機開發伺服器**：
   ```bash
   npm run dev
   ```

5. **在瀏覽器開啟**：
   打開瀏覽器網址列輸入：
   👉 **http://localhost:3000** （或終端機中顯示的網址）即可開始繪製！

## 🪟 如何轉換成 Windows `.exe` 獨立軟體？

我們為您提供了兩種最方便的方式：

### 🌟 方案 A：一鍵打包生成真實 `地鐵路網繪製器.exe`
1. 確保電腦已安裝 [Node.js](https://nodejs.org/)。
2. 在專案資料夾中，**直接滑鼠雙擊執行 `build-exe.bat`**。
3. 程式會自動進行編譯並調用 Electron 打包工具，打包完成後會自動開啟 `dist-exe\` 資料夾。
4. 裡面就會產生一個 **`地鐵路網繪製器.exe`**！
   - 這是**綠色免安裝版**軟體，可以複製到隨身碟或任何 Windows 電腦上直接雙擊打開，完全不需要安裝 Node.js！

---

### 🚀 方案 B：免下載編譯，1 秒將網頁「安裝為桌面獨立應用程式」（與 EXE 效果相同）
現代瀏覽器（Google Chrome 與 Microsoft Edge）原生支援 PWA 桌面應用技術：
1. 打開本專案的線上連結：
   👉 **https://ais-pre-qapnfec7clvo5slsdi2xxk-781784010405.asia-northeast1.run.app**
2. 查看瀏覽器網址列右側，會出現一個 **「安裝應用程式」電腦小圖示 💻**（或點擊瀏覽器右上角選單 `...` 選擇「安裝 地鐵路網繪製器」）。
3. 點擊「安裝」後：
   - 您的 Windows 桌面會立刻生成「地鐵路網繪製器」捷徑圖示！
   - 點開就是**完全獨立的無邊框軟體視窗**（沒有瀏覽器網址列、標籤頁），在 Windows 工作列有專屬圖示，體驗與 `.exe` 完全一模一樣，離線時也能隨時使用！

## 📦 如何打包成可直接部署的純 HTML 靜態網頁？

如果您想將繪製器發布至靜態網站託管服務（如 GitHub Pages、Vercel、Netlify 等），請執行：

```bash
npm run build
```

編譯完成後，專案根目錄會產生 `dist/` 資料夾，裡面的所有 HTML、JS、CSS 都已經過編譯與打包，可直接上傳託管。

本地預覽打包後的檔案：
```bash
npm run preview
```

## ✨ 核心特色功能
- **自由繪製線段與自訂折點**：連點兩次增加節點，右鍵刪除節點。
- **虛擬節點**：黑色圓圈中間叉叉圖示，用於無站點的線路轉折分岔。
- **8 方位站名與自由拖動**：
  - 3×3 羅盤九宮格切換：左上、正上、右上、正左、正右、左下、正下、右下。
  - 直接在畫布上按住站名拖曳至任意位置，具備半透明引導線與精準像素坐標。
- **對齊模式與紅色虛線等距引導**：
  - 按住 `Ctrl` 或開啟「對齊模式」，支援八方向軸向對齊。
  - 連線時檢測與既有線段等距，自動呈現紅色虛線、CAD 雙斜線等長標記與即時等距數值標籤。
- **黑白與日夜自動時控模式**：上午 6 點至下午 6 點自動切換為亮色模式，其餘為深色暗夜模式。
- **5 種連線幾何與內外翻轉**：135° 折線、90° 垂直線、90° 旋轉線、直線、任意角度折線與自由曲線。
